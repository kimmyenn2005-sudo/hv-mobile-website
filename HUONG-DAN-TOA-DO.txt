GHIM BAN DO CHI NHANH HV MOBILE QUANG NGAI
=====================================================

Link ban do tren toan bo website hien dung DIA DIEM DA GHIM
tren Google Maps cua cua hang, KHONG dung so toa do:

    Ten hien thi : HV Mobile Quang Ngai
    Dia chi      : 43 Le Thanh Ton, phuong Cam Thanh, Quang Ngai
    Place ID     : ChIJkTCz6WBTaDERt37BTiZZTbM

Khi khach bam "MO GOOGLE MAPS" se mo thang the dia diem
HV Mobile Quang Ngai (co ten cua hang, anh, danh gia, gio mo cua),
khong hien so toa do va khong the nhay sang Duc Pho.

DOI SANG DIA DIEM KHAC (neu can):
    1. Mo Google Maps, tim dung dia diem cua hang.
    2. Lay Place ID cua dia diem do.
    3. Mo tep  scripts/toa-do.mjs  va sua dong:
           export const QUANG_NGAI_PLACE_ID = "ChIJ...";
    4. Chay:  npm run build  roi  npm run check
    -> Footer, nut CHI DUONG va schema tren MOI trang tu cap nhat.

KIEM TRA SAU KHI DEPLOY:
    1) Mo  https://<ten-mien>/map-check.txt
       Dong "Ban build luc" phai la gio vua deploy.
    2) Mo  https://<ten-mien>/iphone/  -> keo xuong footer
       -> giu vao nut MO GOOGLE MAPS -> copy link.
       Link dung phai chua: query_place_id=ChIJkTCz6WBTaDERt37BTiZZTbM
    3) Thu tren dien thoai bang TAB AN DANH.

BO KIEM TRA TU DONG (`npm run check`):
    Se BAO LOI va chan deploy neu bat ky trang nao con link ban do
    tim theo chu, con link dang toa do, hoac con chu "Duc Pho"/"Mo Duc".
